# BlacksmithVR

## English

**BLACKSMITH VR** is an interactive VR blacksmithing simulator in which players experience the entire weapon crafting process, from material preparation to final assembly.

### Technologies Used

- Unity
- C#
- XR Interaction Toolkit (based on OpenXR)

### Requirements

To run the project, you will need:

- A VR headset
- SteamVR

### How to Run

1. Download the archive.
2. Extract its contents.
3. Run the `.exe` file.

## 🇷🇺 Русский

**BLACKSMITH VR** — интерактивный VR-симулятор кузницы, в котором игрок проходит полный цикл создания оружия: от подготовки материалов до сборки готового изделия.

### Использованные технологии

- Unity
- C#
- XR Interaction Toolkit (на основе OpenXR)

### Требования

Для запуска проекта необходимы:

- VR-гарнитура
- SteamVR

### Как запустить

1. Скачайте архив.
2. Распакуйте его содержимое.
3. Запустите файл `.exe`.
